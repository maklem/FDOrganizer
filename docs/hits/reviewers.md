# Kurzanleitung für Reviewer

* Login
* Wechsel in Tab Review

* Review-Prozess
  * An einem Paket in der linken Liste
    * Mit dem Buch-Symbol öffnet man die Ansicht der Metadaten
      * Es werdem alle verfügbaren Felder gezeigt. Für Inhalte muss man die Kategorien selber aufklappen.
    * Mit dem Listensymbol öffet man die Ansicht für rechtliche Fragen und Revieweinträge
    * Auf ein Paket klicken markiert es und zeigt rechts die Dateien an
  * Für Daten in einem Paket
    * Mit dem Buchsymbol öffnet man die Metadaten
    * Durch klick auf einen Ordner öffnet man diesen innerhalb der rechten Ansicht
* Review Abgeben
  * Akzeptieren
    * Bei einem markierten Paket ist dazu ein Button rechts oben oberhalb der Dateien
  * Ablehnen
    * Dazu muss die Ansicht der rechtlichen Fragen und Revieweinträge geöffnet werden
    * Ein neuer Revieweintrag hinzugefügt werden
    * Abschließend ist rechts unten ein Knopf "Request Changes" verfügbar

* Download
  * bei angenommenen Paketen ist nun ein Button "Download Package" an der Stelle wo zuvor der Button "Accept for Archive" war.
