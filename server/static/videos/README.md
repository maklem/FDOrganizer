# Video tutorials

Video tutorials to introduce users to the FDOrganizer.

## Description

These video tutorials have been developed to encourage researchers to use the FDOrganizer tool independently and to provide assistance with its different areas and functions.
As the FDOrganizer UI is currently only available in English, the videos were also created in English. English subtitles are available in a separate .vtt file.

## Software

- Mouse highlight effect: Microsoft PowerToys
- Screen recording: OBS Studio (version 31.0.0)
- Audio generated using the text-to-speech function in ElevenLabs
- Editing and subtitles: DaVinci Resolve (version 19.1.3)
