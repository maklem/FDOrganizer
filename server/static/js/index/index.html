The FDOrganizer

Pre-Ingest Tool

The tool can be used for data curation and organization before the data is transferred to a long-term archive

Interface to several data sources

A variety of data sources, such as databases or electronic lab notebooks, can be connected to the FDOrganizer

Interface to long-term archiving system

The data is automatically transferred to the connected long-term archive without any additional effort

The Features

Import research data from different source systems

Research data can be imported easily from various connected data sources, such as electronic lab notebooks or databases

Organize and store research data

The data can be organized and arranged in appropriate structures

Add and structure metadata

Metadata can be added and structured at different levels

How to use

Edit

  • Create data package and import the data from different sources
  • Add various metadata

Archive

  • Agreement to the terms of use and definition of further requirements
  • Submit data package

Review

Review of the submitted data package by responsible parties
